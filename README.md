# santibedate.com

Source code of the portfolio of **Santiago Rodríguez Bedate**, Game Designer, Level Designer and Producer.

**Live site:** [www.santibedate.com](https://www.santibedate.com)

Built on [mldangelo/personal-site](https://github.com/mldangelo/personal-site), an MIT-licensed template by Michael D'Angelo, with Next.js 16, React 19, TypeScript and Tailwind CSS v4. Static export, hosted on Vercel.

## Running it locally

Requires Node.js 20 or later.

```bash
npm install
npm run dev      # http://localhost:3000
```

## Checks

```bash
npm run type-check
npm run lint
npm run format:check
npm test
npm run build    # static export to out/
```

## Where things live

- `src/data/`: résumé, projects, companies, About page text
- `public/images/`: screenshots, GIFs and logos
- `app/`: pages and styles
